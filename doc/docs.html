⚡ Hermes Bot

A Discord bot for gaming_Tavern — powered by the Hermes Agent Framework with the personality of Hermes from Hades. Tracks game prices, monitors Steam libraries, delivers patch notes, generates weekly power rankings, and suggests new games to play.

How Skills Work

Each skill is a directory containing a SKILL.md file (instructions for the LLM) and a scripts/ folder (Python scripts that fetch real data). When a user invokes a skill, the LLM reads the instructions and calls the Python script via its terminal tool, then presents the output in Hermes character.

Mention Behaviour

The bot requires an @mention to respond in all channels except the designated home/Hermes channel, where it responds freely. Cron jobs (news, recap) post autonomously to their channels without needing a trigger.

game-news
Fetch patch notes and updates from Steam for the group's shared games

Usage

Invoke /skill game-news manually to see the latest news. Manual queries use --recent mode — they fetch the last 3 relevant items per game directly from Steam without touching the deduplication log, so browsing never interferes with the cron feed.

The cron job (every 4 hours) runs without --recent: it deduplicates against the seen_news table and marks items so they're never re-posted. Summaries are cleaned of HTML tags and BBCode before being passed to the LLM.

Scripts

# Manual query — recent items, no dedup side-effects
python3 news_fetcher.py --recent

# Manual query for a specific game (by Steam App ID)
python3 news_fetcher.py --recent 548430

# Cron mode — deduplicates and marks items seen
python3 news_fetcher.py

Output

NEW_ITEMS: 2
---
GAME: Deep Rock Galactic
TITLE: Update 38: Patch Notes
URL: https://store.steampowered.com/...
DATE: 2026-04-18
SUMMARY: Scout changes, new cosmetics...
---

Deduplication

Cron runs store each posted item's gid in the seen_news table — items are never re-posted. Manual --recent queries bypass this table entirely, so the two modes are fully independent.

How Snapshots Work

On each recap run, current Steam playtime is saved to playtime_snapshots. Next week's recap compares against this baseline to show only this week's activity rather than all-time hours.

💡
First run returns NO_DATA and creates the baseline snapshot. The second run (next week) will produce the actual recap.

game-suggest
Recommend popular co-op games the group doesn't own yet, ranked by deal value

Usage

Invoke /skill game-suggest. No arguments — automatically checks all linked users' libraries and returns up to 5 suggestions.

Script

# skills/game-suggest/scripts/game_suggester.py
python3 game_suggester.py

Algorithm

  1. Collect every game owned by any linked user from user_games
  2. Fetch top "Online Co-op" tagged games from SteamSpy (sorted by owner count)
  3. Filter out any game the group already owns
  4. Look up EUR pricing for each candidate via GG.deals / ITAD (up to 30 candidates checked)
  5. Skip games over €60 at full price
  6. Return top 5 with current price, historical low, and discount percentage

Output

LINKED_USERS: 3
SUGGESTION: Lethal Company | APPID: 1966720 | PRICE: €9.29 | HIST_LOW: €6.99 | DISCOUNT: 0% off | URL: https://gg.deals/game/lethal-company/
SUGGESTION: It Takes Two | APPID: 1426210 | PRICE: €14.99 | HIST_LOW: €7.49 | DISCOUNT: 50% off | URL: https://gg.deals/...

Deployment

Systemd Service

The bot runs as a user systemd service that auto-starts on boot.

# Start / stop / restart
systemctl --user start hermes-gateway
systemctl --user stop hermes-gateway
systemctl --user restart hermes-gateway

# Check status
hermes gateway status

# Live logs
journalctl --user -u hermes-gateway.service -f
tail -f bot.log

Gateway Commands

# Restart gateway (picks up config changes)
hermes gateway restart

# Check connection state
cat ~/.hermes/gateway_state.json

# View loaded skills
hermes skills list

Adding / Updating Skills

Skills live in skills/ and are registered via ~/.hermes/config.yaml external_dirs. Edit a skill's SKILL.md or Python script and restart the gateway:

# Pick up SKILL.md changes and re-sync slash commands
hermes gateway restart

Scheduled Tasks

Cron jobs are managed by Hermes's built-in scheduler. Set them up by telling Hermes in Discord:

Game News (every 4 hours)

/cron add "every 4h" "Fetch new game news for all tracked games and post to channel NEWS_CHANNEL_ID using the game-news skill" --skills game-news

Weekly Recap (Sundays 18:00)

/cron add "0 18 * * 0" "Generate and post the weekly recap and power rankings to channel RECAP_CHANNEL_ID" --skills weekly-recap

Managing Jobs

# List all jobs
/cron list

# Test a job immediately
/cron run <job_id>

# Pause / remove
/cron pause <job_id>
/cron remove <job_id>

Troubleshooting

Bot not responding to messages

ℹ️
Outside the home channel, the bot requires an @mention. Check ~/.hermes/config.yaml — only channel 1494641107844468886 should be in free_response_channels.
hermes gateway status
tail -20 bot.log

Skills not appearing in /skill autocomplete

Skills must be registered in ~/.hermes/config.yaml under skills.external_dirs. After adding a new skill:

hermes skills list          # verify skill appears
hermes gateway restart      # re-sync slash commands

Price showing N/A

The scripts load API keys from .env via skills/_load_env.py. Verify keys are set:

grep "GG_DEALS_API_KEY\|ITAD_API_KEY" .env

game-suggest returns no results

SteamSpy may be temporarily slow (can take up to 20s) or rate-limited. Try again after a minute. If prices are unavailable, verify GG_DEALS_API_KEY and ITAD_API_KEY are set in .env.

Steam library not fetching

  • Go to Steam → Profile → Edit Profile → Privacy Settings → set Game Details to Public
  • Verify STEAM_API_KEY is set in .env
  • If using a vanity URL and it fails, try the numeric SteamID64 instead

Gateway keeps crashing (exit code 75)

Exit code 75/TEMPFAIL is normal — it's how Hermes tells systemd to restart it after a clean shutdown. If it's crash-looping:

journalctl --user -u hermes-gateway.service -n 100 --no-pager
cat ~/.hermes/logs/errors.log

Hermes responds but doesn't run the script

The LLM may be using an older cached version of the SKILL.md. Restart the gateway to reload skill instructions:

hermes gateway restart
